# Security Policy

## Scope

Lyric Editor è un’applicazione web lato client.
Il sito:
- non richiede account
- non raccoglie né salva dati personali
- non utilizza backend o database

Eventuali problemi di sicurezza riguardano esclusivamente:
- il codice JavaScript lato client
- la gestione degli input dell’utente
- l’uso di librerie o dipendenze esterne

## Reporting a Vulnerability

Se viene individuato un problema di sicurezza nel codice di Lyric Editor:

- aprire una Issue su GitHub descrivendo il problema
- evitare la pubblicazione di exploit funzionanti

Le segnalazioni verranno valutate e, se ritenute valide, corrette direttamente nel codice del sito.

## Disclaimer

Data la natura del progetto, Lyric Editor non garantisce un livello di sicurezza adatto ad applicazioni che trattano dati sensibili.
